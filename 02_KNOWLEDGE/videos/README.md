# Videos

Video's en hun transcripten/samenvattingen — de kern, niet de ruwe kopie.

**Kaarttype:** `video` — gebruik de capability-kaart uit `00_SYSTEM/CARD_SCHEMA.md`
en de vulprompt `04_PROMPTS/create_capability_card.md`.

**Voorbeelden van wat hier thuishoort:**
- Een tutorial met een bruikbare techniek
- Een talk met een relevant inzicht

Eén kaart per bestand, `kebab-case.md`. Verwijs naar gerelateerde kaarten in plaats van
te dupliceren.
