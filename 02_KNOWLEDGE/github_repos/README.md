# GitHub Repos

Relevante repositories — wat ze doen, hoe bruikbaar ze zijn, en welke capabilities ze raken.

**Kaarttype:** `github_repo` — gebruik de capability-kaart uit `00_SYSTEM/CARD_SCHEMA.md`
en de vulprompt `04_PROMPTS/create_capability_card.md`.

**Voorbeelden van wat hier thuishoort:**
- Een repo met een herbruikbare techniek
- Een tool-repo die we (deels) willen inzetten

Eén kaart per bestand, `kebab-case.md`. Verwijs naar gerelateerde kaarten in plaats van
te dupliceren.
