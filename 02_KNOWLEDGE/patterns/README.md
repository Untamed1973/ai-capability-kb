# Patterns — de bouwtekeningen

Het hart van de bibliotheek. Niet *welke* tool, maar *hoe* je iets bouwt: de werkwijze,
de valkuilen, de varianten. Dit is wat het verschil maakt tussen een dakkapel die we al
eens bouwden (betrouwbaar, autonoom) en een die nog niemand bouwde (improvisatie, stopt
voor Roel).

**Kaarttype:** `pattern` — zie `00_SYSTEM/CARD_SCHEMA.md`.

Een goede pattern-kaart bevat: het doel, de stappen, welke capabilities het gebruikt, de
valkuilen die we tegenkwamen, en varianten ("voor dit type / die uitstraling"). Elke keer
dat je iets nieuws werkend krijgt, leg je het hier terug als pattern — zo groeit de
bibliotheek en wordt steeds meer werk "bekend werk".
