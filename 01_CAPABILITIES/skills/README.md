# Skills

Herbruikbare, afgebakende vaardigheden die een executor kan inzetten — de doctrine, tone
of voice, werkwijzen en bouwstenen die je telkens opnieuw gebruikt.

**Kaarttype:** `skill` — zie `00_SYSTEM/CARD_SCHEMA.md` en
`04_PROMPTS/create_capability_card.md`.

## Migratie-opdracht (open)

`OPERATOR_ONE_SKILLS_MAP.md` (110 skills, 21 secties) en `OPERATOR_ONE_COMPANION_LAYER.md`
worden hier de levende, canonieke thuisbasis. Die map is uit nood ontstaan omdat er geen
centrale plek was; deze map vervangt 'm. **Te doen:** migreer de skills naar losse
kaarten hier (of een gestructureerde index), markeer de oude map daarna als gemigreerd,
en verwijder 'm pas wanneer de migratie geverifieerd is. Tot die tijd blijft de oude map
de tijdelijke bron — niet beide tegelijk als waarheid behandelen.

Eén kaart per skill (of per cluster), `kebab-case.md`.
