# MCP Servers

Model Context Protocol-servers die tools en data via een protocol beschikbaar maken.

**Kaarttype:** `mcp_server` — gebruik de capability-kaart uit `00_SYSTEM/CARD_SCHEMA.md`
en de vulprompt `04_PROMPTS/create_capability_card.md`.

**Voorbeelden van wat hier thuishoort:**
- Een MCP-server voor een issue-tracker of code-host
- Een MCP-server die bestanden of een dienst ontsluit

Eén kaart per bestand, `kebab-case.md`. Verwijs naar gerelateerde kaarten in plaats van
te dupliceren.
