# CLI Tools

Command-line tools die via de terminal worden aangeroepen.

**Kaarttype:** `cli_tool` — gebruik de capability-kaart uit `00_SYSTEM/CARD_SCHEMA.md`
en de vulprompt `04_PROMPTS/create_capability_card.md`.

**Voorbeelden van wat hier thuishoort:**
- ffmpeg voor mediabewerking
- git, of een projectspecifieke CLI

Eén kaart per bestand, `kebab-case.md`. Verwijs naar gerelateerde kaarten in plaats van
te dupliceren.
