# Agents

Autonome of semi-autonome AI-agents die taken zelfstandig uitvoeren of orkestreren.

**Kaarttype:** `agent` — gebruik de capability-kaart uit `00_SYSTEM/CARD_SCHEMA.md`
en de vulprompt `04_PROMPTS/create_capability_card.md`.

**Voorbeelden van wat hier thuishoort:**
- Een research-agent die meerdere bronnen samenvat
- Een agent die een repo analyseert en een plan maakt

Eén kaart per bestand, `kebab-case.md`. Verwijs naar gerelateerde kaarten in plaats van
te dupliceren.
