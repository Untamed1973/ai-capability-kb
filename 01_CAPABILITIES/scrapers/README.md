# Scrapers

Tools en scripts die data van bronnen ophalen, binnen de regels van INGESTION_RULES.md.

**Kaarttype:** `scraper` — gebruik de capability-kaart uit `00_SYSTEM/CARD_SCHEMA.md`
en de vulprompt `04_PROMPTS/create_capability_card.md`.

**Voorbeelden van wat hier thuishoort:**
- Een website-parser (URL → gestructureerde data)
- Een transcript-ophaler voor video's

Eén kaart per bestand, `kebab-case.md`. Verwijs naar gerelateerde kaarten in plaats van
te dupliceren.
