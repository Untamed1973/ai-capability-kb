# Executors

De systemen die taken daadwerkelijk uitvoeren op een machine of in de cloud.

**Kaarttype:** `executor` — gebruik de capability-kaart uit `00_SYSTEM/CARD_SCHEMA.md`
en de vulprompt `04_PROMPTS/create_capability_card.md`.

**Voorbeelden van wat hier thuishoort:**
- Claude Code (lokaal, op de MacBook)
- Codex
- GitHub Action

Eén kaart per bestand, `kebab-case.md`. Verwijs naar gerelateerde kaarten in plaats van
te dupliceren.
