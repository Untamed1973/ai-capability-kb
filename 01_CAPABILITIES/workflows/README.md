# Workflows

Vaste, herhaalbare ketens van stappen die meerdere capabilities combineren tot een resultaat.

**Kaarttype:** `workflow` — gebruik de capability-kaart uit `00_SYSTEM/CARD_SCHEMA.md`
en de vulprompt `04_PROMPTS/create_capability_card.md`.

**Voorbeelden van wat hier thuishoort:**
- Brand-foundation: URL/PDF → parser → gestructureerd profiel
- Content-pipeline: brief → posts → review

Eén kaart per bestand, `kebab-case.md`. Verwijs naar gerelateerde kaarten in plaats van
te dupliceren.
