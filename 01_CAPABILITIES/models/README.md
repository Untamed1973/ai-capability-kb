# Models

De taalmodellen en multimodale modellen die we kunnen inzetten, inclusief de
beschikbare abonnementen. Eén kaart per model/provider.

**Kaarttype:** `model` — zie `00_SYSTEM/CARD_SCHEMA.md`.

**Nu beschikbaar (te bekaarten):** Claude (Anthropic), OpenAI, Gemini (Google). Nieuw
model of nieuwe provider = nieuwe kaart. Noteer per model vooral de beslisvelden:
kosten/prijsmodel, snelheid, kwaliteit/sterktes, toegang (API/app), en lock-in. Zo kan de
router kiezen welk model het beste past bij een taak — soms Claude, soms een ander.
