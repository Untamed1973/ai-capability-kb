# Metadata

Gestructureerde index-data over de kaarten (tags, statussen, relaties, completeness).
Voor nu met de hand of door een prompt te genereren; later door de index-/nightly-laag.

Idee voor een eenvoudige eerste index: een tabel of JSON met per kaart: pad, type, status,
trust level, completeness, tags. Daarop kunnen lenzen (cockpit, verrijkingslijst) draaien.
