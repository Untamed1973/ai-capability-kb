# Changelogs

Automatisch en handmatig gegenereerde wijzigingslogs over kaarten en bronnen — vooral
voor de nightly-update (zie `04_PROMPTS/nightly_update.md`).

Onderscheid met `DECISION_LOG.md`: het decision log gaat over *waarom het systeem
verandert* (governance, met de hand). Changelogs gaan over *wat er feitelijk veranderde*
aan bronnen/kaarten (bv. een repo kreeg een nieuwe release). Een nightly-run mag hier
schrijven, maar mag mensreviews nooit overschrijven zonder de wijziging te markeren.
